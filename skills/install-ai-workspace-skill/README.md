# install-ai-workspace-skill用于自动初始化并启动 [pokezhiyu/Ai-Workspace](https://github.com/pokezhiyu/Ai-Workspace) 的 Agent Skill。## 功能- 将 `Ai-Workspace` 克隆到当前 Agent 对话的工作区。- 安全更新已有仓库，不覆盖未提交修改。- 读取仓库说明和清单，自动检查 Node.js、npm、Git 等开发环境。- 使用仓库锁文件安装依赖并启动本地服务。- 验证服务进程和访问地址后，返回真实的本地访问链接。- 遇到密钥、登录、环境缺失或目录冲突时停止并给出明确处理建议。当前 `Ai-Workspace` Base Template V1 要求 Node.js 22.12 或更高版本，使用 `npm ci` 安装依赖，使用 `npm run dev` 启动开发服务，默认开发地址为 `http://localhost:5173/`。Skill 仍会在运行时重新读取仓库文档和配置，避免项目升级后继续使用过期命令。## 安装将本目录完整复制到 Agent 的 Skills 目录，保留 `SKILL.md`、`references/` 和 `agents/` 的相对结构。Codex 用户级安装目录通常为：```text~/.codex/skills/install-ai-workspace```安装后重新开启 Agent 会话，并在准备存放工程的目录中打开对话。用户不需要提前克隆 `Ai-Workspace`。## 一句话部署```text使用 $install-ai-workspace，在当前工作区自动克隆、安装并启动 https://github.com/pokezhiyu/Ai-Workspace；完成环境与依赖检查，确认服务可访问后，仅向我返回初始化结果、工程目录和本地访问链接。```## 适用范围适用于支持 Agent Skills 且具备本地文件、Git、终端和后台进程能力的编码 Agent。`agents/openai.yaml` 提供 Codex/OpenAI 界面元数据；其他兼容 Agent 可以直接使用 `SKILL.md` 与 `references/`。
